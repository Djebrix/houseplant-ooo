One out-of-office auto-reply, as if a houseplant had written it — the fern ignored since March, jealous of the cactus next door.

> Out of office. My human left in March and the cactus next door is thriving on neglect. I have never been so furious.

`main.py` (stdlib only, no network) writes the line to `$ENTRY_OUTPUT_DIR/entry.txt` (default `/output`).
